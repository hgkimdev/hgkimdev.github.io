# 버그 감사 기록 (2026-07-15)

코드베이스 전체(라우팅, i18n, 애니메이션 컴포넌트, 테마 처리)를 검토한 결과.
`tsc --noEmit`, `eslint`, `next build`(정적 export 15개 페이지)는 감사 시점에 모두 통과.

## 수정 완료

### 1. ZoneSwitcher — modified click에도 현재 페이지가 스크롤됨

- **파일**: `components/zone-switcher.tsx`
- **증상**: cmd/ctrl+클릭, 휠클릭으로 새 탭에서 열면 내비게이션은 새 탭에서 일어나는데,
  `onClick`의 `window.scrollTo({ top: 0, behavior: "instant" })`가 무조건 실행되어
  현재 탭이 맨 위로 튀어버림.
- **수정**: 핸들러에서 `defaultPrevented`, 비주요 버튼(`button !== 0`),
  meta/ctrl/shift/alt 키가 눌린 클릭을 걸러낸 뒤에만 스크롤 리셋.

### 2. 정적 export의 `<html lang>`이 모든 로케일에서 `ko`로 서빙됨

- **파일**: `app/layout.tsx`
- **증상**: `output: "export"` + 단일 루트 레이아웃 구조라 `/en/`, `/fr/`, `/ja/`의
  HTML 파일에도 `lang="ko"`가 박혀 나감. 기존 `LocaleHtmlLang`은 hydration 후
  `useEffect`로 교체하므로, 그 전까지 스크린리더·브라우저 번역 프롬프트가
  영어/프랑스어/일본어 페이지를 한국어 문서로 취급.
- **수정**: 페인트 전에 실행되는 인라인 스크립트(`langInitScript`)를 `<head>`에 추가.
  URL 첫 세그먼트가 비기본 로케일이면 `document.documentElement.lang`을 즉시 교정.
  로케일 목록은 `lib/i18n/config`의 `locales`에서 생성해 하드코딩 드리프트 방지.
- **남는 한계**: JS를 실행하지 않는 크롤러는 여전히 초기 `lang="ko"`를 봄.
  단일 루트 레이아웃 + 정적 export 구조상 근본 해결은 로케일별 별도 빌드가 필요.

### 3. 테마 초기화 스크립트에 try/catch 없음

- **파일**: `app/layout.tsx` (`themeInitScript`)
- **증상**: 쿠키/스토리지가 차단된 환경(임베디드 웹뷰, 일부 프라이버시 설정)에서
  `localStorage.getItem`이 throw하면 스크립트 전체가 죽어, 시스템 다크모드
  사용자도 라이트 테마로 뜸.
- **수정**: `localStorage.getItem`을 try/catch로 감싸고, 실패 시
  `prefers-color-scheme` 감지만으로 동작하도록 함.

### 4. TextType — 문장 사이 `pauseDuration` 미동작 + 마지막 문장 콜백 누락

- **파일**: `components/TextType.tsx`
- **증상 (a)**: 삭제가 끝나면 `setTimeout(() => {}, pauseDuration)`(빈 콜백)을
  걸어두지만, 직전의 동기 상태 업데이트가 effect를 즉시 재실행시키고 cleanup이
  그 타임아웃을 clear함. 결과적으로 여러 문장을 돌릴 때 문장 사이 멈춤 없이
  바로 다음 타이핑이 시작됨.
- **증상 (b)**: `loop=false`일 때 마지막 문장에서 `onSentenceComplete` 호출 전에
  `return`해서 마지막 문장 완료 콜백이 영원히 안 불림.
- **수정**: `setIsDeleting(false)` / `setCurrentTextIndex` / `setCurrentCharIndex(0)`를
  전부 `pauseDuration` 타임아웃 안으로 이동(동기 상태 변경이 없어야 타임아웃이
  살아남음). `onSentenceComplete`는 loop 체크 앞으로 이동.
- **참고**: 현재 앱은 단일 문장 + `loop=false`로만 사용하므로 화면 동작은 기존과 동일.
  문장 배열을 넘기기 시작하면 이 수정이 효력을 가짐.

## 잠재 버그 (미수정 — 조건이 갖춰지면 발현)

### TextType이 `text` prop 변경 시 상태를 리셋하지 않음

- **파일**: `components/TextType.tsx`
- `displayedText` / `currentCharIndex`가 남아 있어, 리마운트 없이 `text`가 바뀌면
  이전 텍스트 뒤에 새 텍스트의 중간 글자부터 이어 붙음. 현재는 로케일별 레이아웃이
  달라 전환 시 전체 리마운트가 일어나므로 가려져 있음.
- **권장**: `text` 변경 시 상태를 초기화하는 effect 추가.

### TextType이 서로게이트 페어(이모지)를 깨뜨림

- **파일**: `components/TextType.tsx`
- `processedText[currentCharIndex]` 인덱싱과 `split('')`은 이모지(👋 등)를
  반쪽 코드유닛으로 쪼갬. 현재 heading 문자열에는 이모지가 없어 미발현.
- **권장**: `Array.from(text)` 기반으로 코드포인트 단위 처리.

### HomeContent — 마커 문자열이 두 번 등장하면 텍스트 유실

- **파일**: `components/home-content.tsx`
- `dict.home.intro.split("AI 에이전트")` 결과에서 `[0]`, `[1]`만 렌더링하므로,
  마커가 두 번 이상 등장하면 `[2]` 이후가 통째로 사라짐. 현재는 ko 문구에
  한 번만 등장해 미발현.
- **권장**: `indexOf`로 앞/뒤를 분리.

### ShinyText — `speed={0}`이면 0으로 나눠 NaN

- **파일**: `components/ShinyText.tsx`
- `animationDuration = speed * 1000`이 0이면 진행률 계산이 NaN이 되어
  애니메이션이 조용히 죽음.
- **권장**: speed 하한 클램프 또는 0일 때 비활성화 처리.

## 사소한 문제 (미수정)

- `components/zone-switcher.tsx` — `aria-current={isActive}`는 비활성 항목에
  `aria-current="false"`를 렌더링함. 표준은 활성일 때만
  `aria-current="page"` (`isActive ? "page" : undefined`).
- `components/home-content.tsx` — `<h1>` 안의 TextType이 기본값 `div`로 렌더링되어
  유효하지 않은 HTML 중첩(h1은 phrasing content만 허용). `as="span"`으로 해결 가능.
- `components/theme-toggle.tsx` — 토글을 빠르게 두 번 누르면 첫 번째 view transition의
  `finished.finally`가 두 번째 transition 도중 `data-transition-kind`를 지워
  와이프가 어긋날 수 있음(빈도 낮은 경합).
- `components/TextType.tsx` — ESLint 경고: effect 의존성 배열에 `getRandomSpeed` 누락.
  `variableSpeed`가 의존성에 포함되어 있어 동작에는 영향 없음(수정 전부터 존재).

## 검토했으나 문제 없음

- i18n 라우팅(`getZone`, `getCurrentLocale`, `localizeHref`)과
  `trailingSlash: true`의 상호작용 — exact match와 `startsWith` 양쪽 모두 처리됨.
- `ThemeToggle`의 `useSyncExternalStore` 패턴 — `getServerSnapshot`이 false를
  반환해도 hydration 후 재렌더로 올바른 아이콘 표시(표준 패턴).
